# Student Management System

A small Python project I built while learning Python and OOP.

The program manages students, their grades and courses using a JSON file.

### What I practiced

* Python OOP (`class`, methods, `@classmethod`)
* Working with JSON
* Lists and dictionaries
* Reading and writing files
* Basic data validation

### Features

* View students and their average grades
* Find the student with the highest average
* Move students to the next course
* Add grades
* Save changes to JSON

**Tech:** Python, JSON
